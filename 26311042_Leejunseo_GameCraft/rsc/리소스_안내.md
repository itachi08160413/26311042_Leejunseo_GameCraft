# 리소스 사용 현황

| 경로 | 용도 |
| --- | --- |
| images/kitchen-alternative/background.png | 주방 배경 |
| images/chef/player.png, player_left.png | 요리사 방향 이미지 |
| images/kitchen/pack/Container/4pan.png | 팬 |
| images/kitchen/pack/Ingredient/food/9pancake.png, 9pancake-cooked.png | 생반죽/적정 음식 |

| audio/interface-sounds/Audio/confirmation_001.wav | 회수 |

나머지 파일은 원본 팩/후보로 보관한다. 원본 팩을 삭제하거나 라이선스를 분리하지 않았다. 현재 빌드는 후보를 포함한 rsc 전체를 복사한다. 배포 용량 축소는 별도 정리 대상이다.

## 출처와 사용 조건

- 주방/팬/음식: PtPt. 원본 images/kitchen/pack/License.txt 및 licenses/REQUIRED_CREDITS.txt 참고.
- 배경, 요리사: 기존 확보한 원본과 기존 출처 기록을 유지한다. 요리사 개별 출처·조건의 최종 확인이 필요하다.
- 효과음: Kenney interface sounds. audio/interface-sounds/License.txt 유지.
- 배경음: Kevin MacLeod의 Carefree, CC BY 4.0. licenses/REQUIRED_CREDITS.txt의 크레딧 유지.
- 음식 아이콘 후보, 불꽃 팩, 글꼴은 현재 코드에서 사용하지 않는다. 해당 원본의 라이선스를 함께 보관한다.

음식 뒤집기·불꽃은 코드 애니메이션이며, 탄 상태는 실패 안내 후 즉시 제거한다. 별도 탄 이미지나 불꽃 스프라이트는 로드하지 않는다.
