## 2. 게임 소개 및 목표

플레이어는 조리대 앞을 좌우로 이동하는 요리사다. 조리대의 팬에서 익어 가는 팬케이크를 확인하고, 알맞은 순간에 뒤집어 양면을 완성한다. 여러 팬의 조리 시간을 살피며 이동할 순서를 판단하는 것이 핵심이다.

한 판은 90초이며, 제한 시간 동안 200점 이상을 획득하면 성공한다. 실패가 5회 누적되면 시간이 남아 있어도 게임이 종료된다. 점수와 시간 등 수치는 최초 구현 기준이며 실제 플레이 후 조정한다.

## 3. 화면 구성

- 시작 화면: 게임 제목, 조작 방법, 시작 안내를 표시한다.
- 게임 화면: 위쪽에는 남은 시간, 점수, 실패 횟수를 표시한다. 중앙에는 가로로 배치한 팬 4개와 음식의 익힘 표시를, 아래쪽에는 좌우로 이동하는 요리사를 배치한다.
- 결과 화면: 성공 또는 실패, 최종 점수, 완성한 음식 수, 재시작 안내를 표시한다.

현재 상호작용할 수 있는 팬에는 테두리를 표시한다. 음식은 색뿐 아니라 상태 문구와 게이지로도 익힘 정도를 구분한다.

## 4. 조작 방법

| 키 | 기능 |
| --- | --- |
| 왼쪽 / 오른쪽 방향키 | 요리사 좌우 이동 |
| Space | 선택된 팬의 음식 뒤집기 또는 완성 음식 회수 |
| Enter | 시작 화면에서 게임 시작, 결과 화면에서 새 게임 시작 |
| Esc | 게임 종료 |

요리사는 화면 안에서만 이동한다. 각 팬 앞에 정해진 상호작용 구역을 두고, 요리사가 그 구역에 있을 때만 해당 팬을 조작한다. 팬 사이에서는 아무 팬도 선택되지 않는다. Space는 누르는 순간 한 번만 처리하며, 길게 눌러도 동작이 반복되지 않는다. 빈 팬을 조작해도 불이익은 없다.

## 5. 음식 조리 규칙

음식은 빈 팬 중 한 곳에 자동으로 생성된다. 플레이어가 반죽을 붓거나 음식을 운반하는 과정은 없다. 팬 하나에는 음식 하나만 놓이며, 가득 찼을 때는 생성을 건너뛴다.

음식의 진행은 다음과 같다.

```text
빈 팬 → 첫 면 조리 → 뒤집기 → 둘째 면 조리 → 회수 → 빈 팬
                         ↓                 ↓
                  너무 이르거나 늦으면 실패
```

- 첫 면이 적정 상태일 때 Space를 누르면 음식이 뒤집히고 둘째 면의 조리 시간이 시작된다.
- 둘째 면이 적정 상태일 때 Space를 누르면 완성 음식이 회수되고 점수를 얻는다.
- 어느 면이든 적정 시간 전에 조작하면 덜 익은 음식으로 실패한다.
- 적정 시간을 넘기면 자동으로 탄 음식으로 실패한다.
- 실패한 음식은 즉시 제거하고 실패 횟수를 1회 올린다. 같은 음식의 실패를 중복 집계하지 않는다.
- 뒤집는 동안에는 그 음식의 조리 시간을 잠시 멈추고 중복 입력을 받지 않는다. 애니메이션이 끝나면 둘째 면 조리를 시작한다.

### 음식 종류와 조리 시간

| 종류 | 적정 상태가 되는 시간 | 적정 상태 유지 시간 | 특징 |
| --- | --- | --- | --- |
| 일반 팬케이크 | 각 면 4초 후 | 2초 | 기본 음식 |
| 얇은 팬케이크 | 각 면 3초 후 | 1.5초 | 중반부터 등장하는 빠르게 익는 음식 |

예를 들어 일반 팬케이크는 각 면의 조리 시간이 4초 이상 6초 미만일 때 조작해야 한다. 4초 전에는 덜 익은 상태이고, 6초에 도달하면 탄다. 얇은 팬케이크는 3초 이상 4.5초 미만이 적정 상태다.

## 6. 점수와 종료 조건

| 상황 | 처리 |
| --- | --- |
| 첫 면을 알맞게 뒤집음 | 둘째 면 조리 시작, 점수 변화 없음 |
| 둘째 면까지 완성하여 회수 | 10점 획득, 완성 음식 수 1 증가 |
| 너무 일찍 조작하거나 음식이 탐 | 실패 횟수 1 증가, 음식 제거 |
| 실패 5회 누적 | 즉시 게임 실패 |
| 90초 종료 시 200점 이상 | 게임 성공 |
| 90초 종료 시 200점 미만 | 게임 실패 |

목표 점수를 먼저 달성해도 제한 시간까지 계속 플레이한다. 제한 시간 종료 시 남아 있는 음식은 추가 실패로 계산하지 않는다. 실패 5회와 시간 종료가 같은 시점에 발생하면 실패를 우선한다. 결과 화면으로 이동한 뒤에는 조리와 점수 계산을 멈추고, 재시작하면 모든 상태를 초기화한다.

## 7. 난이도 및 콘텐츠 확장

별도 맵 대신 한 판 안에서 시간에 따라 조리 상황이 바뀐다.

| 경과 시간 | 사용할 팬 | 음식 생성 간격 | 등장 음식 |
| --- | --- | --- | --- |
| 0초 이상 30초 미만 | 가운데 2개 | 4초 | 일반 팬케이크 |
| 30초 이상 60초 미만 | 4개 | 3초 | 일반 / 얇은 팬케이크 |
| 60초 이상 90초 미만 | 4개 | 2.5초 | 일반 / 얇은 팬케이크 |

첫 음식은 게임 시작 직후 생성한다. 중반부터는 두 음식 종류를 같은 확률로 생성한다. 단계가 바뀌어도 이미 조리 중인 음식의 시간은 바꾸지 않는다. 팬 수 증가, 생성 간격 감소, 조리 시간이 다른 음식 추가로 플레이 내용을 확장한다.

## 8. 애니메이션 및 동적 표현

- 요리사: 좌우 이동 시 걷기 애니메이션을 재생한다.
- 음식: 조리 시간에 따라 생반죽, 적정 상태, 탄 상태로 이미지를 바꾸고 게이지를 갱신한다.
- 뒤집기: 약 0.3초 동안 음식이 위로 올라갔다 내려오는 동작을 표현한다.
- 조리대: 불꽃을 반복 애니메이션으로 표현한다.
- 완성 및 실패: 짧은 점수 표시 또는 실패 표시와 효과음을 출력한다.

움직임과 조리 시간은 프레임 수가 아니라 실제 경과 시간을 기준으로 계산한다. 음식 상태 이미지 교체만으로 끝내지 않고 요리사 이동, 음식 뒤집기, 불꽃 애니메이션을 함께 구현한다.

## 9. 주요 클래스와 역할

기본 프로젝트의 앱과 시작·플레이·결과 장면 구조를 활용한다.

| 클래스 | 역할 |
| --- | --- |
| CApplication | 창과 라이브러리 초기화, 리소스 관리, 장면 전환 |
| SceneGameBegin | 제목과 조작 안내 표시, 시작 입력 |
| SceneGamePlay | 팬 4개 관리, 음식 생성, 타이머·점수·난이도·종료 판정 |
| SceneGameResult | 최종 결과 표시, 재시작 입력 |
| Player | 좌우 이동, 걷기 애니메이션, 선택 팬 판정 |
| Food | 종류, 조리 중인 면, 익힘 상태, 조리 시간과 뒤집기 동작 관리 |

팬은 고정 위치와 음식 보유 여부를 가진 간단한 데이터로 관리한다. 별도 물리 엔진은 사용하지 않고 요리사의 위치와 팬의 상호작용 구역을 비교하여 판정한다.

## 12. 구현 범위와 완성 확인

이번 프로젝트는 좌우 이동, 음식 뒤집기와 회수, 시간에 따른 상태 변화에 집중한다. 주문, 음식 운반, 레시피 조합, 상점, 성장, 멀티플레이는 구현 범위에 포함하지 않는다.

완성 시 다음 항목을 확인한다.

- 시작 화면에서 게임을 시작하고 결과 화면에서 다시 시작할 수 있다.
- 플레이어가 선택한 팬의 음식만 조작하며 키를 길게 눌러도 중복 처리되지 않는다.
- 적정 시간 전·중·후에 각각 덜 익음·성공·탐 판정이 일관되게 동작한다.
- 팬이 가득 차도 음식이 겹쳐 생성되지 않으며, 실패한 음식은 한 번만 집계된다.
- 시간에 따라 팬 수, 음식 종류, 생성 간격이 바뀐다.
- 걷기, 뒤집기, 불꽃 애니메이션이 실제 게임 중 재생된다.
- 시간 종료, 목표 점수, 실패 5회 조건이 올바르게 판정된다.
- 결과 화면에서는 시간이 흐르지 않고 재시작 시 점수·음식·타이머가 초기화된다.
- 다른 프레임 속도에서도 이동과 조리 시간이 일정하게 유지된다.
