# 팬케이크 실행 및 4차 제출 확인

Visual Studio에서 `26311042_Leejunseo_GameCraft/26311042_Leejunseo_GameProject.sln`을 열고 x64 Release로 빌드한다. PowerShell에서는 저장소의 `build.ps1`을 실행할 수 있다. 이 환경의 MSPDB140.DLL 버전 오류를 피하도록 Release 빌드의 디버그 정보 생성을 끄고, 스크립트에서 전체 프로그램 최적화를 끈다. 실행 파일과 같은 위치에 rsc 폴더가 필요하며 빌드 시 자동 복사된다.

- Enter: 시작 / 결과 화면에서 재시작
- 좌우 방향키: 이동. 팬의 노란 테두리가 선택 표시다.
- Space: 초록색 적정 상태에서 첫 면 뒤집기 / 둘째 면 회수
- Esc: 종료
- 다른 창으로 전환하면 플레이가 일시 정지된다.

90초 동안 200점이 목표이며 완성 음식당 10점, 실패 5회면 즉시 종료한다. 일반 음식은 각 면 4~6초, 얇은 음식은 3~4.5초 사이에 조작한다. 게이지의 흰 선부터 초록색 구간이 적정 시간이다. 뒤집는 0.3초 동안 조리는 정지한다.

0~30초는 가운데 팬 2개·4초 간격, 30~60초는 팬 4개·3초 간격, 이후는 2.5초 간격이다. 얇은 음식은 30초부터 등장한다. 결과 화면은 멈춘 상태이며 Enter를 누르면 모두 초기화한다.

## 구현 현황

시작/플레이/결과/재시작, 음식 자동 생성, 선택 팬 판정, 양면 조리, 중복 입력 방지, 점수/실패/종료 조건, 단계별 난이도를 구현했다. 음식 뒤집기 궤적과 불꽃은 코드로 애니메이션 처리한다. 걷기는 좌우 방향 이미지와 상하 움직임으로 표현하며 전용 걷기 프레임 교체는 아직 없다. UI는 한국어이며 맑은 고딕을 사용한다.

## 제출 전 수동 확인

- Enter를 길게 눌러도 한 번만 시작되는지 확인
- 가운데 팬으로 이동하고 적정 상태 전에 눌러 실패가 한 번만 증가하는지 확인
- 적정 상태일 때 뒤집고 둘째 면 적정 상태일 때 회수하여 10점을 얻는지 확인
- 조작하지 않아 탄 음식이 한 번만 실패 처리되는지 확인
- 5회 실패 결과 및 재시작 초기화 확인
- 30초 이후 팬 4개와 얇은 음식, 60초 이후 생성 간격 변화 확인
- 90초에서 200점 미만 실패 / 이상 성공 확인
- 음량과 이미지 배치 확인, 최종 난이도는 실제 플레이로 조정

로직 자동 검증 소스는 `tests/GameStateTests.cpp`이며 assert 기반이다. 아직 f4 태그는 생성하지 않았다. 최종 플레이 확인 후 제출할 커밋에 태그를 붙인다.

## 한국어 UI

시작 화면에서 3단계 조작 안내를 제공한다. 플레이 중 점수 진행 막대, 남은 시간, 실패 횟수를 표시하고 시간 15초 이하 또는 실패 4회 이상이면 경고색을 사용한다. 선택한 팬의 상태에 따라 다음 행동을 안내하며, 덜 익은 음식 조작과 탄 음식의 실패 원인을 구분한다. 하단 설명에는 어두운 배경을 사용한다. 화면의 Enter, Esc 표기는 실제 키 이름이다.

`build.ps1` 실행 결과는 `26311042_Leejunseo_GameCraft/x64/Release/KoreanUI/26311042_Leejunseo_GameProject.exe`에 생성된다. 실행 파일과 rsc 폴더를 함께 보관한다.
